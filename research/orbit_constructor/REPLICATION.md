# Within-task replication and information controls

Heath Sanchez — 28 November 2026. Frozen before the calls below.

The first continuation's two trace-informed programs passed 80/80; two
reconstructions passed 63/80, losing the 17 correlated obstruction inputs.
That four-sample result is CANDIDATE, not a population effect or breakthrough.
It also confounds extra traces with repetition of the failure records. This
new stage tests that confound and an ordinary-execution-information control.
All source, witnesses and failures remain exposed development. There is no
new independent problem family, current upstream bug or acquisition-cost win.

Eighteen independent API calls: six per arm, GPT-6.2-sol low, at most 6000
output tokens/call, no retry or adaptive prompt changes. Each receives the
identical original construction prompt/response, C1 source and four previously
chosen input/expected/actual regression records. No successful C2 code or
outcome enters a prompt. The same four failures are repeated in an additional
four-record block in every arm, so repetition and record count are matched.

* trace: the failed C1's actual independently replayed callback observations.
* sham: the same failure records with empty observation arrays.
* ordinary: the same failure records plus the unchanged operation's native
  result on each original input. These observations are replayed separately;
  they are not manufactured, shuffled or falsely labelled.

Arm labels do not appear in prompts. No special instruction characterizes
empty data as a weaker reconstruction. Real information content and token
length differ; this is an intervention on evidence, not an equal-information
economic comparison. Both controls may reconstruct any investigation or code.
Queries are counterbalanced by a fixed six-block order in replicate.py.

Primary outcome is complete success on the frozen 80-case qualification gate
for each generated program, not the number of correlated fixtures it passes.
Four previously concealed regression inputs remain absent from all prompts.
All 131 original fixtures are a separately reported development diagnostic.
All native callbacks are replayed independently without the generated code;
complete executable replay should tie, with the parent absent at runtime.

Use one-sided Fisher exact tests for trace versus sham and trace versus
ordinary, Holm correction for these two predeclared comparisons at 0.05.
Promotion of this within-task signal requires both corrected tests to reject,
trace having more qualification successes than each control, no API transport
UNKNOWN, and native replay agreement. Invalid generated code is a failed
construction; API transport errors remain UNKNOWN and block promotion. Model
samples, not fixture rows, are the sampling units. Independence/exchangeability
of API responses is a working statistical assumption, not proved by distinct
response IDs. The earlier exploratory four samples are not pooled.

A positive result warrants only evidence-dependent construction in this
single calibration. It cannot establish an intrinsic artifact necessity,
superiority to an equally informed conventional investigator, general
recursive improvement, cross-domain transfer, novelty or economic advantage.
A negative or tied result supersedes the exploratory signal's promotion.
All earlier programs/results and the setup failure remain preserved. Full
costs include the rejected parent and four exploratory successor calls.
