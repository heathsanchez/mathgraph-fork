# Executable critic transfer V2 — frozen before acquisition and future execution

The prior trial trained advisory prose in an engineered guard vocabulary, displayed
inactive guidance to the model, had an oversized rejected graph reflection, and
counted four easy final repairs without testing an emitted critic/constructor.
Those results remain historical: no learning advantage was demonstrated.

This correction separates a construction-and-causal-reuse claim from superiority.
The first is the primary mechanism target. Neither a tie nor a win establishes
new research priority, global recursion, or discovery of a new mathematical law.

## Frozen experiment

1. Replay the exposed MarkupSafe incomplete repair and author implementation from
   run46103184004 against the twelve documented-behavior development examples.
   Supply native outcomes, the contract and the two striptags methods to generation.
2. Ask the same model, gpt-5.6-sol/low, in two independent 6000-output-token calls
   to produce three inspectable Python functions: applicability, diagnostic and
   repair executor. Retained and equally informed cold construction get exactly
   the same prompt and training evidence. Neither sees the other's source or any
   later fixture/answer. Record full acquisition and native qualification costs.
3. Validate source syntax/scope, then execute only in a separate nonroot, read-only,
   network-disabled Docker job with no model/GitHub credential. Require an actual
   replayed training rejection, preservation of all author outcomes and withdrawal
   under single-layer or unspecified contracts. Invalid candidates remain rejected.
   Freeze exact program bytes before opening any later software source or tests.
4. Use actual ftfy PR9 parent and author source, plus w3lib v2.1.2 (fallback ref
   2.1.2) and the independent property-test commit1e4960e9a6494d8c5192744c6cdda28401b1fb8a.
   No source edits or synthetic buggy implementations. Extract ftfy's entire
   TEST_CASES list and the author's own extra-encoding transformation; add its
   explicit nested-entity contract example. For w3lib extract the first100 distinct
   literal-input/literal-output asserts per safe_url_string/canonicalize_url in
   AST traversal order, with default arguments only and fixed size bounds.
   Future input/expected pairs are external author fixtures; their expected answers
   are withheld from learned programs and only supplied to the independent scorer.
5. Require each asserted future expectation to be reproduced by the pinned author
   implementation before scoring that fixture for any variant. Failures are
   UNKNOWN_AUTHOR_ORACLE and remain in raw evidence. Never filter using a learned
   critic's outcome. Historical public data is an inference holdout, not a guarantee
   of no model pretraining exposure or investigator blindness.
6. ftfy's pre-v3 source is a real migration candidate evaluated under the v3 author
   contract. Do not claim v2 violated a promise it did not make. Future target
   functions include actual independently authored Unicode repair and URL code;
   this is not cross-family proof-theorem transfer or universal soundness.

## Counterfactuals and safeguards

Each frozen program sees a black-box string operation, seed and documentary
contract. Only actual operation results may be returned as repairs. At most12
observations per case; timeout/resource limits yield UNKNOWN. A diagnostic is
terminal finite counterexample evidence only when its scope is supported and the
underlying different first/second outputs are independently replayed. No observed
failure is not proof of correctness. Diagnostics may be incomplete.

Run the same future source/seed/contract with retained program, independent cold
reconstruction, a strong conventional fixed-point method, no learned critic,
diagnostic removed, repair constructor removed and byte-identical ledger replay.
The familiar fixed-point method is deliberately an explicit baseline; rediscovering
it is not mathematical novelty. Report ties and conventional wins.

Python html.unescape and urllib.parse.unquote are real single-layer controls.
Correct default behavior must be preserved. Forcing applicability is a separate
negative intervention; it must never silently redefine the target's contract.

Hard selection guarantees an inactive learned module has no influence on selected
ordinary context. The old advisory harness is patched accordingly and has direct
byte-identity tests; old run results are not replaced. Executable critics are gated
by their actual applicability function before invocation.

## Outcomes

Primary: an acquired and finitely qualified executable diagnostic plus constructor
causally changes a later native outcome and matches an independently verified
author expectation; removing diagnosis or constructor loses the correction.
Require exact ledger replay parity and enumerate false rejections/damage on valid
controls. This is a bounded mechanism claim, separate from measured performance.

Secondary: compare equally informed construction and the conventional method,
including construction/qualification, program observation counts and runtime. No
superiority claim from a forced import, absent feature, deliberately weak baseline,
or reusing the same author implementation through a wrapper.

Preserve every failure, UNKNOWN, program, prompt/response, source/test identity,
environment census and actual native call/result. Record old-interface observation
collisions only if actual observations coincide; do not infer universal impossibility
from bounded failure or claim all alternative discovery procedures are blocked.
