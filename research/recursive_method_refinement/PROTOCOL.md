# Recursive method refinement — bounded native preflight

Objective: test three successive acquisitions with a fixed LLM and independently checked executable constructors. This is a deliberately small, constructed finite numeric benchmark using Python's native math.dist and sum as the protected oracle; not independent open-world software discovery, unrestricted new primitive invention, or a superiority claim.

Frozen before inference:
- Stage 1: acquire a generic constructor for 1-D separation, after the projection-only investigator fails.
- Stage 2: after earlier constructors fail, propose a new constructor for total variation of three measurements. It can call a previously qualified constructor.
- Stage 3: after earlier constructors fail, propose a constructor for the absolute difference of overlapping three-measurement total variations.
- Source fields are anonymous, with a nuisance field. For each stage use a development and a distinct renamed/rebound transfer population; each is the complete Cartesian domain {-2,-1,0,1,2} over its fields. Deterministic disjoint calibration and holdout. Model sees only development calibration examples and a source-independent contract. It never receives the transfer population or holdout labels.
- Fixed finite generic constructor language, no prelisted winning formulas. Template parameters F0..F3 are rebound by exhaustive injective assignment; prior qualified templates can be called as O1/O2. Candidate verification uses the existing safe structural interpreter, not arbitrary generated code.
- One API response per arm per eligible stage (maximum six calls, 1600 output tokens/call, no retries). Same model and training evidence, same calibration matcher and source access. Direct comparator sees the expanded prior methods, but proposes a standalone template without named macros. Equal-information conventional expansion may tie.
- Before calling the LLM, exhaust prior retained constructors on development calibration. If a prior constructor succeeds, stop this stage rather than claim a new necessity. Missing earlier receipts do not justify promotion.
- Each credential-free stage verifier checks all development and transfer rows, preserves failure and usage, qualifies only exact complete native outputs, checks macro withdrawal (syntax/lineage) and unrolled semantic sham (not dependent on named macro). Report calibration probe counts, heldout row counts, tokens, model calls and all UNKNOWNs; do not call macro removal alone proof of causal discovery. Strong comparator, sham, and acquisition costs can defeat superiority.
- All three stages must qualify, have actual named predecessor dependencies, and beat matched control at a declared cost/outcome boundary before claiming bounded comparative advantage; even then strict autonomous G2/G3 and full lifecycle advantage remain UNKNOWN. Candidate grammar and task structure are deliberately supplied. No production mutations, no external effects, no secrets in logs/artifacts. Independent verifier separate from model credentials.
- Scientific failure is an admissible result; preserve all attempts. Do not use an overall green workflow to imply a successful invention chain.
