# Native recursive investigator — preregistered bounded trial
2026-11-27. No toy tasks. Research-only branch; no upstream changes.

## Question
Can a fixed LLM learn an executable investigation method from real software repair evidence, improve it using later evidence, and cause more correctly repaired defects under a matched context/call budget? Mere formula reuse, author-patch replay, localization, and successful CI are not proof of recursion.

## Authority and selection (before opening candidate source)
Use actual merged bug-fix PRs, in fixed order: mahmoud/boltons, toolz/toolz, pypa/packaging, python/typing_extensions, SethMMorton/natsort, jaraco/zipp, python-jsonschema/referencing, python-jsonschema/jsonschema, python-babel/babel, pyparsing/pyparsing. Read at most 100 closed PR metadata per repo; sort eligible merged PRs by number descending; consider at most eight metadata-eligible PRs per repo. Select the first native-admitted defect per repository, stop after six. Cohort 1 first two, cohort 2 next two, cohort 3 last two. No replacements based on any model answer. All failed admissions retained. Projects are selected to avoid known prior project studies; global nonexposure/model-training nonexposure cannot be guaranteed.

Eligibility: ordinary correctness defect (exclude security/vulnerability/auth-related titles); actual merge first-parent diff includes exactly one modified Python production file and one modified existing Python test file, other changes only documentation; no dependency/build/config changes. Source change <=100 lines and expressible as one existing named function/method replacement. Native admission: exact author post-merge test file over original parent source gives actual assertion failure; same exact test file over author merge source passes those failures and preserves every original passing test identity, at least three passing controls, no collection errors; test selection full file, not just new test. No hidden author fix, PR title/body or location revealed to model except completed earlier cohorts. Require stable native outcome and interpreter/dependency identity. No source claims outside this selected-file regression boundary. Record exact source SHAs, paths, hashes, full test identities, failed admission causes and author location for scoring only. Repo distinct cohorts; all future sources withheld from model prompts until their stage.

## Investigator
- Candidate source functions/methods with stable IDs. Both arms see same function inventory, exact failing test diagnostic, previous receipts (including all previously learned method expressions), same code-context budget and exactly one repair API call per eligible task. Both see the same source summary and candidate metadata; selected top two function bodies are acquired from the shared inventory by their method. Repair must replace only one or both supplied complete functions, not tests/requirements/verifier. No model-generated code on a credential-bearing runner. Native tests run in nonroot isolated Docker without network, credentials, Docker socket or write access to checked-out source.
- Initial method fixed deterministic rank from actual traceback, test/source token overlap and function names. Cohort 1 uses the fixed policy (one repair call/task), and after verification an LLM proposes an executable scoring expression in the existing restricted expression interpreter; it sees actual native outcomes and author location of completed tasks. No fixed menu of scoring policies, but the observable feature vocabulary and pure grammar are supplied and explicitly bounded.
- Cohort 2 compare fixed direct policy vs learned O1; both receive the same earlier evidence. After native evaluation ask LLM to improve the ranking method O1 using prior results, freeze O2 before opening cohort 3 for inference. O2 can consume O1 as a previous-score feature. An invalid or unsupported expression is UNKNOWN, not replaced after seeing heldout.
- Cohort 3 evaluate fixed direct, O1 only, O2, and O2 with O1 score physically withheld (zeroed). All four get equal history and equal one-call/repair budget per task. An informed conventional rank (Ochiai-style + lexical relevance) is also scored for localization, not presented as a native repair comparator. All candidate repairs independently native-tested against exact author file, not accepted based on matching author code.
- Primary metric: independently verified repair (all original pass IDs retained and all author failing IDs now pass; no errors/new failures/new skips). Secondary: author repair location rank/top-two, API usage, native process counts, time, failed attempts, candidate scope; no broad lifecycle or superior architecture claim from this small cohort. Predecessor deletion is only causal evidence if held-out outcome actually changes, not merely a missing reference. Matched arms may tie; no forced pass or retuning on future outcomes.
- Maximum repair calls: cohort1 2, cohort2 4, cohort3 8, plus two method calls; 16 total, no retries; fixed model gpt-5.6-sol (low), output <=2400 tokens per call. If insufficient native cases or API errors, preserve UNKNOWN. No substitute fixtures; no secrets printed/uploaded. Actual source code patches only in temporary native verifier and no production mutation. A general model may have memorized published fixes, which cannot be excluded. This is a prospective evaluator/source-withholding experiment within the experiment, not a time-travel guarantee.
- Promotion: native actual repair is WARRANTED_BOUNDED only at exact source/test/environment. Strict G2/G3 requires more than this: newly learned method must change actual downstream repair outcome and later method acquisition/use; fixed baseline and ablation must fail within matched budgets, with independent controls. Otherwise UNKNOWN. No claims of unrestricted invention or net economics.
